Install a Bookmarklet

Drag a link in the Drag to install column onto the bookmarks bar, and that bookmarklet is installed under the name on the link. It holds the same code the repository README gives as a raw file to copy, joined onto one line the way a bookmark's address field joins it, so a bookmarklet installed from here and one pasted by hand are the same bookmarklet.

No bookmarks bar to drag onto? Right click the link, copy its address, then make a new bookmark and paste that as the URL. Or open the raw file, select all, copy, and paste that instead, line breaks and all, which is what the files are written for.

What the statuses mean:

  • ready to use - install it and use it as it is. 47 of the 54 are.
  • requires N changes - the file says near the top what to change, so open the raw file, change those lines, and paste the result rather than dragging the link. The link installs the file unchanged, which does less than the file can.
  • tested by hand - still maintained, but its page is one no automated run opens, so a person tests it.
  • deprecated - kept in the repository as a record and not offered to install: its site now does the job itself, or a better tool does. Its README entry says which.

The example gallery shows what some of them do, and lists practice pages to try the ones that work on any page on.
