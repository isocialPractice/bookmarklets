Bookmarklet Examples

What these examples are

Each example below is a page that ChatGPT - Paste Ready Bookmark Response saved as a bookmark. The bookmarklet copies a ChatGPT answer to the clipboard as a bookmarklet of its own; pasting that as the URL of a bookmark gives a bookmark that writes the answer back out as a page. What the frame shows is what a reader sees on opening one of those bookmarks, answer, table and all.

The bookmarklet that wrote them: the raw file to paste, its gist, and a short showing it run. Every bookmarklet in the repository is listed in the repository README.

Installing one

Open the raw file, press Ctrl + A then Ctrl + C, and paste the whole of it as the URL of a new bookmark. The line breaks come out when it is pasted, which is why the files are written the way they are.

Practice pages

Pages to try the bookmarklets that work on any page on, rather than on a site of your own. They are the same pages the test harness runs against, so a page you can try is a page a test has already checked, and nothing on them reaches the network.

  • An article - try Clutter - click to hide, Clipboard - make a markdown link list, DOM search page, Window style - bold, italic, underline, highlight and URI - anchor highlighted text.
  • A table - try Clipboard - convert page to markdown, which brings the tables back as pipe tables, and Clipboard - make a markdown link list.
  • A form - try Note - take page notes and Clutter - click to hide. The form sends nothing.
  • A page with a sidebar - try Sidebar - fix and scroll the side menu, Sidebar - underline the anchor link and Sidebar - highlight the current page.
  • A page with a video - try Video - take video notes and Note - take page notes.
  • A page that keeps loading - try Parse - stop page parsing and Parse - stop page parsing at the parsed height.
  • A long page - try PageOffset - custom page down.
  • One of each - try Clipboard - convert page to markdown, whose whole output fits on a screen here.

Each page repeats its own list, and the index of the practice pages holds all eight.
